# PINDOU Image Edit

一个可直接安装到 **ComfyUI** 的自定义节点：把输入图片转换成拼豆/像素马赛克，并生成带有 **A–H、M 系列色号符号、每 5 格坐标线和用量统计图例** 的制作图纸。

节点内置 4 套 **MARD 官方标准 RGB 色板**：原有 221 色完整色板，以及 AI96、AI72、AI32 三套优化色板。颜色匹配在 CIE Lab 感知色彩空间中完成，比直接比较 RGB 更接近人眼观感；节点生成的所有色块都严格来自当前选择的色板，不会产生所选色板之外的颜色。

## 节点输出

节点名称：`拼豆马赛克图纸（带色号）`

节点位置：`图像 → 拼豆 PINDOU`

输出包括：

1. **马赛克预览**：已经匹配到实体色卡的纯色块预览图。
2. **带色号图纸**：每格显示色号，并可附坐标和色号用量图例。
3. **色号统计**：JSON 文本，包含画板尺寸、总豆数，以及每个色号的 HEX 色值和数量。

支持 ComfyUI 的图片批次输入；不同高度的图纸会自动补白后组成批次。

## 安装

进入 ComfyUI 的 `custom_nodes` 文件夹后执行：

```bash
git clone https://github.com/QY-1111/PINDOU-image-edit.git
```

然后重启 ComfyUI。这个节点只使用 ComfyUI 已自带的 PyTorch、NumPy 和 Pillow，不需要额外安装依赖。

如果使用 Windows 便携版，常见安装位置是：

```text
ComfyUI_windows_portable/ComfyUI/custom_nodes/PINDOU-image-edit
```

## 使用

1. 添加 `Load Image / 加载图像`。
2. 添加 `图像 → 拼豆 PINDOU → 拼豆马赛克图纸（带色号）`。
3. 把加载图像的 `IMAGE` 接到节点的 `image`。
4. 将两个图片输出接到 `Preview Image` 或 `Save Image`。

仓库中的 [`examples/workflow_api.json`](examples/workflow_api.json) 是一个 API 格式的最小工作流示例。

## 参数说明

当 ComfyUI 界面语言设为“中文（简体）”时，节点会显示下表中的中文名称；内部参数名继续保留，确保旧工作流和 API 调用兼容。

| 中文界面名称 | 内部参数 | 说明 |
| --- | --- | --- |
| 横向拼豆数 | `bead_width` | 横向拼豆数量。纵向数量按照原图比例自动计算；最长边安全限制为 300 格。 |
| 最大颜色数 | `max_colors` | 最多使用多少种实体色号。默认 24 色；数值越大越接近原图，备料越复杂。 |
| 色板 | `palette` | 可选原有 MARD 221 色、AI96、AI72 或 AI32。选定后，取色、抖动、图例与统计都会限定在该色板内。 |
| 缩放方式 | `resize_method` | 面积平均适合照片；高质量锐化缩放（Lanczos）边缘更锐；最近邻适合原本就是像素画的输入。 |
| 抖动方式 | `dither` | 默认关闭，色块更干净；误差扩散（Floyd-Steinberg）可用有限颜色模拟渐变，但会产生交错色点。 |
| 单格尺寸 | `cell_size` | 输出图中每格的像素大小，影响可读性和图片尺寸，不影响拼豆数量。 |
| 显示色号 | `show_symbols` | 是否在每个格子内显示 A1、H7 等色号。 |
| 显示坐标 | `show_coordinates` | 是否每 5 格显示坐标并加粗网格线。 |
| 显示图例 | `show_legend` | 是否在图纸底部显示色号、色块和用量。 |
| 图纸标题 | `title` | 图纸顶部标题。 |
| 外边缘强化 | `enhance_outer_edge` | 连接可选遮罩后，将遮罩内侧的一格轮廓强化为黑色；未连接遮罩时保持原有处理。 |
| 网格线不透明度 | `grid_line_opacity` | 拼豆格子分割线的不透明度滑块，范围 0–1；默认 0.35，数值越小线条越淡。 |
| 色号字号 | `symbol_font_scale` | 格内 A1、H7 等色号文字的字号比例滑块，范围 0.2–0.8；默认 0.4。 |
| 外边缘遮罩（可选） | `mask` | 用于指定外边缘强化范围的遮罩，不连接也可正常运行。 |

当画板非常大时，节点会自动降低实际单格显示尺寸，把最长输出边控制在合理范围内，避免生成超大图片导致内存不足。

## 建议设置

- 人像、宠物：宽度 48–80，颜色 20–32，关闭抖动。
- 卡通图标：宽度 32–64，颜色 8–20，关闭抖动。
- 风景或渐变：宽度 64–100，颜色 24–48，可尝试 Floyd-Steinberg。
- 打印图纸：`cell_size` 建议 20–32，并开启符号、坐标和图例。

## 色板选择

- `MARD 221色（原色板）`：保留原节点的完整色板与默认行为。
- `MARD AI96（96色）`：颜色覆盖较完整，适合照片、人像和较丰富的插画。
- `MARD AI72（72色）`：在颜色表现与备料数量之间取得平衡。
- `MARD AI32（32色）`：面向 30×30 等小尺寸图案，颜色更集中、备料更简单。

例如选择 `MARD AI96（96色）` 后，即使“最大颜色数”设置得更高，生成结果也只会使用 AI96 中的色号。

## 色彩说明

节点使用提供的 MARD 221 色标准 RGB 数值。显示器色彩管理、打印机、环境光线以及不同批次的实体拼豆仍可能带来视觉色差；制作重要作品前，建议拿实际拼豆色卡核对少量关键颜色。
